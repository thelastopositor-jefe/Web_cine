# TuRodaje — primera adaptación (NO PUBLICAR TODAVÍA)

Esta entrega es una primera adaptación, no una migración terminada.

- Firebase web apunta a `webcine-e2af5`, y `.firebaserc` también.
- Azul de clases Tailwind de `App.jsx` cambiado a rojo.
- Navegación: Cursos, Oportunidades, Actualidad.
- Tipo de producción: Acción real, Documental, Experimental, Híbrido.
- Formulario de contacto deshabilitado hasta tener un correo propio.
- Etiquetas de Google Tag Manager y verificación del sitio original eliminadas de index.html.
- El logo, las imágenes, el catálogo, datos de ejemplo, textos interiores, reglas de seguridad, funciones, permisos de administrador y otros recursos de ToonKnight requieren una segunda revisión.
- No desplegar Firebase ni habilitar escrituras hasta revisar reglas de Firestore/Storage y cuentas administrativas.
- `turodaje.com` es un dominio previsto, aún no registrado.

Para probar únicamente la interfaz: `npm install` y `npm run dev` desde la carpeta del proyecto. No iniciar sesión ni enviar datos reales todavía.
